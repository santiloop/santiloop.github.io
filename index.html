Proyecto Barber: turnos para barberíasProyecto Barber: barbershop bookings

Un sistema web terminado para una barbería, con dos lados: los clientes piden turno desde el celular y el local maneja la agenda, los barberos, los horarios y los números del mes.

A finished web system for a barbershop, with two sides: customers book from their phone, and the shop runs the agenda, the barbers, the hours and the monthly numbers.

Capturas y videosScreenshots and videos

El problemaThe problem

Ordenar los turnos de una barbería: qué barbero atiende, en qué horario y qué días no se trabaja.

Keeping a barbershop’s bookings in order: which barber, at what time, and which days are closed.

Qué haceWhat it does

Un sistema web con dos lados: los clientes piden turno desde el celular y el local maneja la agenda, los barberos, los horarios y un reporte mensual.

A web system with two sides: customers book from their phone, and the shop runs the agenda, the barbers, the hours and a monthly report.

  • Portal para clientes: se registran con su teléfono y piden turno viendo solo los horarios libres.Customer portal: people sign up with their phone number and book, seeing only the free slots.
  • Agenda del local con el estado de cada turno: confirmar, iniciar atención, reprogramar o cancelar.The shop’s agenda shows each booking’s status: confirm, start, reschedule or cancel.
  • Horarios por barbero y días no laborables: no se dan turnos fuera de horario y el sistema sugiere barbero.Hours per barber and closed days: no bookings outside them, and the system suggests a barber.
  • Avisos para el dueño y un reporte mensual de ausentismo y recaudación, descargable en PDF.Notifications for the owner and a monthly report on no-shows and revenue, downloadable as PDF.
  • Cada cliente puede pedir hasta 2 turnos por mes; reprogramar o cancelar no cuenta.Each customer can book up to 2 appointments a month; rescheduling or cancelling does not count.
  • El dueño carga los servicios con duración y precio, los barberos y sus franjas horarias.The owner sets up services with duration and price, the barbers and their time slots.
  • Usuarios con login, roles y cambio de contraseña.Users with login, roles and password change.

Cómo está hechoHow it is built

  • Antes de programar documenté los casos de uso.Before writing code, I documented the use cases.
  • Solución en capas sobre .NET 10: base de datos (entidades y DbContext), repositorio, servicios, proyecto compartido, la API y el cliente.Layered solution on .NET 10: database (entities and DbContext), repository, services, a shared project, the API and the client.
  • Pantallas en Blazor WebAssembly y una API en ASP.NET Core con 12 controladores.Screens in Blazor WebAssembly and an ASP.NET Core API with 12 controllers.
  • Entity Framework Core con SQL Server para los datos.Entity Framework Core with SQL Server for the data.
  • Login con JWT y permisos por rol: por ejemplo, solo el dueño puede dar de alta o modificar barberos.JWT login and role-based permissions: for example, only the owner can add or edit barbers.
  • Las reglas del negocio se validan en la API: horarios por barbero y días no laborables.Business rules are checked in the API: each barber’s hours and closed days.
  • Endpoints documentados con Swagger, con botón para probarlos con el token del login.Endpoints documented with Swagger, with a button to try them with the login token.

De punta a punta: casos de uso, modelo de datos, API y pantallas.

End to end: use cases, data model, API and screens.

Asistente de WhatsApp para talleres mecánicosWhatsApp assistant for car repair shops

Un asistente para el WhatsApp de un taller mecánico. La idea: que conteste solo cuando un cliente pregunta si su auto está listo y que arme los pedidos de turno con los datos del auto, para que el mecánico solo tenga que aceptar o rechazar.

An assistant for a repair shop’s WhatsApp. The idea: it answers on its own when a customer asks whether their car is ready, and it puts together appointment requests with the car’s details, so the mechanic only has to accept or decline.

La idea, en títeres de sombraThe idea, in shadow puppets

El problemaThe problem

Un mecánico pierde mucho tiempo contestando “¿ya está el auto?” y preguntando qué le pasa a cada auto antes de dar un turno.

A mechanic spends a lot of time answering “is my car ready?” and asking what is wrong with each car before booking it in.

Solución propuestaProposed solution

Un asistente que conteste solo cuando preguntan si el auto está listo y que arme los pedidos de turno con el modelo y el problema, para que el mecánico solo acepte o rechace.

An assistant that answers on its own when someone asks whether their car is ready, and puts together booking requests with the model and the problem, so the mechanic only accepts or declines.

  • El mecánico marca cada auto con un tilde cuando está listo. Si el cliente pregunta, el asistente detecta la consulta y responde solo.The mechanic ticks each car when it is ready. When a customer asks, the assistant recognises the question and answers on its own.
  • Si alguien pide un turno, el asistente le pregunta el modelo y el problema, revisa la agenda del taller y le manda al mecánico la solicitud con un día sugerido.When someone asks for an appointment, the assistant asks for the model and the problem, checks the shop’s schedule and sends the mechanic the request with a suggested day.
  • El mecánico acepta o rechaza, y recién ahí el asistente le contesta al cliente.The mechanic accepts or declines, and only then does the assistant reply to the customer.

Cómo va a funcionarHow it will work

  1. El cliente escribe por WhatsApp, como siempre.The customer writes on WhatsApp, as usual.
  2. El asistente detecta si es una consulta por el estado del auto, un pedido de turno o algo que no le corresponde.The assistant works out whether it is a question about the car, an appointment request or something it should not handle.
  3. Si es un turno, pide lo que falta (modelo y problema) y revisa la agenda del taller.For an appointment, it asks for whatever is missing (model and problem) and checks the shop’s schedule.
  4. Le manda al mecánico la solicitud resumida, con una posible causa y un día sugerido.It sends the mechanic a summary of the request, with a possible cause and a suggested day.
  5. El mecánico acepta o rechaza, y recién ahí el asistente le contesta al cliente.The mechanic accepts or declines, and only then does the assistant reply to the customer.
  6. Lo que no entiende, se lo pasa al mecánico.Anything it does not understand goes to the mechanic.

Rutina: planes de gimnasio por linkRutina: gym workout plans by link

Una app web para gimnasios, pensada para el celular. El profe arma un plan y le manda un link al alumno, que ve su rutina tocando los músculos de una figura del cuerpo, carga lo que entrenó y sigue su progreso.

A mobile-first web app for gyms. The trainer builds a plan and sends the member a link; the member sees their routine by tapping the muscles on a body diagram, logs each workout and follows their progress.

La idea, en títeres de sombraThe idea, in shadow puppets

El problemaThe problem

En muchos gimnasios la rutina queda en un papel o en un chat. El alumno no siempre sabe cómo hacer cada ejercicio y no ve cómo progresa.

In many gyms the workout plan lives on paper or in a chat. Members don’t always know how to do each exercise, and they can’t see their progress.

Solución propuestaProposed solution

Una app web para el celular: el profe arma un plan y se lo manda por link; el alumno ve cómo hacer cada ejercicio y anota pesos y repeticiones para seguir su progreso.

A mobile web app: the trainer builds a plan and sends it as a link; the member sees how to do each exercise and logs weights and reps to follow their progress.

  • El profe arma un plan y le manda un link al alumno, sin registro ni contraseña.The trainer builds a plan and sends the member a link, with no sign-up or password.
  • El alumno toca un músculo en una figura del cuerpo y ve los ejercicios de su plan, con fotos, pasos y errores comunes.The member taps a muscle on a body diagram and sees the exercises in their plan, with photos, steps and common mistakes.
  • Carga peso y repeticiones de cada serie y sigue su progreso en una planilla.They log weight and reps for every set and follow their progress in a sheet.
  • El profe tiene un panel con login para crear planes y desactivar links.Trainers get a login-protected panel to create plans and disable links.

Cómo está pensadaHow it is designed

  • Blazor Web App con interactividad en el servidor, en .NET 10.Blazor Web App with server-side interactivity, on .NET 10.
  • SQLite con Entity Framework Core: la base se crea y se carga sola al arrancar.SQLite with Entity Framework Core: the database creates and seeds itself on start-up.
  • Cada plan se abre con un link de código largo y aleatorio, que el profe puede desactivar.Each plan opens from a link with a long random code, which the trainer can disable.
  • Panel del profe con login (ASP.NET Core Identity) y sin registro público.Trainer panel with login (ASP.NET Core Identity) and no public sign-up.
  • Límite de intentos por IP y solo los datos mínimos: alias, plan, pesos y repeticiones.Rate limiting per IP and only the minimum data: alias, plan, weights and reps.
  • Pruebas con xUnit e instalable en el celular como PWA.Tests with xUnit, and installable on a phone as a PWA.

Una plataforma para que las familias encuentren profes particulares por materia y por zona, vean sus perfiles y reseñas y les pidan una clase. La estamos desarrollando entre cuatro estudiantes de la tecnicatura.

A platform where families find private tutors by subject and area, see their profiles and reviews, and request a class. Four of us from the software development course are building it.

La idea, en títeres de sombraThe idea, in shadow puppets

El problemaThe problem

Conectar a familias que buscan clases particulares con docentes, por materia y por zona.

Connecting families looking for private tutoring with teachers, by subject and area.

Solución propuestaProposed solution

Una plataforma donde las familias buscan docentes por materia y zona, ven sus perfiles y reseñas y les piden una clase.

A platform where families look for teachers by subject and area, see their profiles and reviews, and request a class.

  • Perfiles de docentes con materias, tarifa por hora, ubicación y reseñas.Teacher profiles with subjects, hourly rate, location and reviews.
  • Búsqueda y filtrado de docentes.Teacher search and filters.

Cómo lo estamos haciendoHow we are building it
